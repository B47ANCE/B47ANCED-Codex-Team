# New Project Template

This is a scaffold for NEW projects only. Replace placeholders with verified project facts. Do not overlay on existing repositories without reviewing provenance and versions.

Maintain a reviewed `docs/MOD_OVERVIEW.json` alongside feature and integration
changes using the installed team hub `docs/MOD-OVERVIEW.md`. Generate a draft
with the existing canonical version and actual source digest; describe source,
foundation, planned and blocked features separately. Do not invent runtime proof.
