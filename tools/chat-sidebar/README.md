# Codex All Existing Chats
Original B47ANCE companion extension, MIT licensed. Lists your own non-archived
local primary chats in the official Codex sidebar using read-only SQLite metadata.
No transcripts are parsed, copied or imported. Selecting a row delegates to the
official extension; no prompt or model turn is submitted automatically.
Requires local Python 3.11+, VS Code 1.106+ and openai.chatgpt. Desktop/local
Windows use only; remote/WSL histories are separate. See team docs/CHAT-SIDEBAR.md.
